# Sprint_6 — UI-автотесты для сервиса «Яндекс.Самокат»

## О проекте

В рамках шестого спринта Яндекс Практикума разработан набор UI-автотестов для учебного сервиса «Яндекс.Самокат».

Проект реализован с использованием Selenium WebDriver, Pytest и паттерна Page Object Model (POM). Для формирования отчётов о выполнении тестов используется Allure Report.

## Проверяемая функциональность

### Раздел «Вопросы о важном»

Проверено отображение ответов на все вопросы FAQ. Для каждого вопроса реализован отдельный тест.

### Оформление заказа

Проверен полный позитивный сценарий оформления заказа:

- оформление заказа через верхнюю кнопку «Заказать»;
- оформление заказа через нижнюю кнопку «Заказать»;
- заполнение формы заказа;
- подтверждение создания заказа;
- отображение окна об успешном оформлении заказа.

Тесты выполняются с использованием двух различных наборов тестовых данных.

### Навигация

Проверены переходы:

- по логотипу «Самокат» — на главную страницу;
- по логотипу Яндекса — открытие главной страницы Дзена в новой вкладке.

## Установка проекта

Клонировать репозиторий:

git clone <ссылка_на_репозиторий>
Перейти в папку проекта:

cd Sprint_6
Создать виртуальное окружение:

python -m venv venv
Активировать окружение.

Windows

venv\Scripts\activate
Linux/macOS

source venv/bin/activate
Установить зависимости:

pip install -r requirements.txt
## Запуск тестов

Запуск всех тестов:

pytest
Подробный вывод:

pytest -v
## Формирование Allure-отчёта

Запуск тестов с сохранением результатов:

pytest --alluredir=allure_results
Создание отчёта:

allure serve allure_results
или

allure generate allure_results -o allure_report
## Особенности проекта

- Для организации кода используется паттерн Page Object Model, что делает тесты более читаемыми и удобными для сопровождения.
- Повторяющиеся сценарии объединены с помощью параметризации Pytest.
- Каждая страница приложения описана отдельным Page Object.
- Отчёты Allure позволяют быстро анализировать результаты выполнения тестов.
